# Supermarket Sales Analysis & Interactive Dashboard

A Power BI dashboard project exploring supermarket sales performance, profitability, and customer purchasing patterns.

## Project Overview

This project analyzes supermarket transaction data to evaluate sales performance and profitability across product lines, months, and customer segments. Power BI was used to transform transaction data into business metrics and interactive visualizations.

**Project Type:** Dummy / Practice Project

## Tools & Skills

- Microsoft Power BI
- DAX Measures
- Data Preparation
- KPI Development
- Data Visualization
- Interactive Dashboard Design
- Business Performance Analysis

## Project Process

1. **Data Preparation:** Imported the dataset into Power BI and checked data types and values before analysis.
2. **Business Metrics:** Created DAX measures to calculate revenue, 5% tax, net revenue, profit, and gross profit margin (GPM).
3. **Performance Analysis:** Compared revenue across product lines, explored monthly profit trends, evaluated average customer ratings, and visualized product quantities by payment method.
4. **Dashboard Development:** Built KPI cards, charts, and a product-line performance table with conditional formatting. Added interactive slicers for gender, customer type, and month.

## Key Analysis Areas

- **Sales Performance:** Compare revenue across product lines.
- **Profitability:** Monitor profit trends by month and evaluate gross profit margin.
- **Customer Experience:** Explore average customer ratings.
- **Purchasing Patterns:** Examine product quantities by payment method and explore customer segments using interactive filters.

## Dashboard Features

- KPI cards for key business metrics.
- Charts for sales and profit analysis.
- Product-line performance table with conditional formatting.
- Interactive slicers for gender, customer type, and month.
